# 数据、覆盖与权利说明

本库包含 100 个模型和 1000 条案例记录。它是供决策学习与检索使用的有限历史快照，不是代表性统计样本、完整历史数据库或已经证明可迁移的因果知识库。

**资料核查日期为 2026-10-12，事件筛选截止为 2025-12-31。ClinicalTrials.gov 数据来源为美国国家医学图书馆（NLM）；本包不反映 NLM 当前最新、最准确的数据，也不获得 NLM 或任何原始机构的背书。** 筛选截止只限制收录事件的时间，不能把 2026 年读取的字段当作 2025 年当时已知的完整版本。

## 两个层级

| 层级与范围 | 数量 | 记录单位与用途 |
| --- | ---: | --- |
| 既有种子深度案例 | 10 | 已有案例复盘，逐条看来源与限制 |
| NASA LLIS 深度案例 | 50 | 一个独立 Lesson ID 的驱动事件、经验与建议 |
| CFPB 深度案例 | 30 | 一个执法程序的背景、机构动作与有出处的结果 |
| 技术深度案例 | 10 | 一个技术实践、事故或应用事件 |
| FDIC 事实事件 | 300 | 一条 `RESTYPE=FAILURE` 的历史 API 记录 |
| CFPB 事实事件 | 200 | 一个独立案件 URL 的官方目录记录 |
| ClinicalTrials.gov 事实事件 | 250 | 一个 NCT ID 的有限登记与主要结果字段 |
| 诺贝尔科研事实事件 | 150 | 一个年度、一个科研授奖类别，合并该类别全部获奖者 |

当前案例关联 37 个模型，另有 63 个模型尚无本地案例关联；1000 条记录不表示每个模型都有 10 个案例，也不表示各学科均衡覆盖。不要为凑齐映射而把不适用的模型附加到事件上。

`deep_case` 有背景、动作、结果、模型映射和迁移限制，但未声称重建全部历史、核对所有附件或完成系统性因果识别。`evidence_event` 有有限事实、稳定事件键、字段快照和定位，不能用它补写未读取的决策过程、人物动机或成功原因。

监管记录的 `regulatory_action` 表示所记录的机构动作；它不自动表示刑事定罪。事实事件统一使用 `documented_event`，不把失败、获奖或随机研究的标签升级为因果结论。模型卡片的证据类型也各不相同，应同时阅读适用条件与误用提示。

## FDIC：300 个历史银行失败事件

数据来自 [FDIC BankFind Suite API](https://api.fdic.gov/banks/docs) ，读取端点为 [银行失败与援助数据](https://api.fdic.gov/banks/failures?limit=10000&format=json) ，字段定义见 [官方 failure_properties.yaml](https://api.fdic.gov/banks/docs/failure_properties.yaml) 。

原始读取含失败与援助两类。这里只取 `RESTYPE=FAILURE`、年份不晚于 2025 的记录；按失败日期与 `ID` 排序，再在有记录的年份之间轮转选取 300 条，覆盖 1934 至 2025 年。轮转扩大历史跨度，不代表各年代失败率、机构类型或资产规模的比例，也不代表美国全部银行。

保留 `ID`、机构名、地点、`CERT`、`FIN`、`FAILDATE`、`FAILYR`、`RESTYPE`、`QBFASSET` 和 `QBFDEP` 等字段。`ID` 是数据行键，不等于银行证书号 `CERT` 或处置编号 `FIN`。资产与存款以**千美元**计，为失败生效日期前的最后报告值，不应解释为失败当天余额；历史空值保持为空。名义金额未做通胀调整，不应直接跨年代比较。

官方数据证明所列机构、日期、处置类别和报告金额，不证明监管失误、挤兑机制、资产质量或单一失败原因。要做失败原因研究，需补充当时财报、监管材料、宏观条件及合适的比较。

[Data.gov 的该数据集条目](https://catalog.data.gov/dataset/bank-failures-and-assistance-data) 将其分发许可标为美国政府公共领域。保留 FDIC 归属与字段出处；这一许可不包括无关第三方附件、商标，也不适用于本仓库全部文字与代码。

## CFPB：30 个深度案例与 200 个目录事件

事实事件来自 [CFPB 官方执法目录](https://www.consumerfinance.gov/enforcement/actions/) 的实际分页内容，保留标题、`Date filed`、目录描述、案件 URL 与页码。以规范案件 URL 去重，排除深度案例及已识别的相关底层事件；Apple Card 的 Apple 与 Goldman Sachs 相关记录没有被分别计入两层以增加数量。

目录事件只支持目录所列的案件名称、日期和有限程序动作。它不代表逐条阅读了投诉书、同意令或所有后续文件。30 个深度案例另行读取官方完整案件页与必要公告或程序文件，主张定位精确到段落、事件日期或文件页码。

区分以下状态：监管机构指控、机构在同意令中作出的认定、当事人的承诺或义务、法院裁决、实际支付以及后续修改或撤销。罚金和退款被要求支付，不等于已履行。目录的 `Date filed` 不等于原始行为开始日、最终裁决日或款项到账日。实时网页可能在历史截止之后更新，卡片只能采用有明确时间依据的历史内容。

[CFPB 官方网站隐私与法律声明](https://www.consumerfinance.gov/privacy/website-privacy-policy/) 说明 CFPB 创作的信息为公共领域，可以在适当归属下使用；网站也可能包含第三方受版权保护的材料。公开可访问的全部附件不因此获得统一许可。本仓库发布原创中文事实改述与必要定位，不包含机构徽标，不暗示 CFPB 背书。

## ClinicalTrials.gov：250 个结果登记事件

实际读取 [ClinicalTrials.gov API v2](https://clinicaltrials.gov/api/v2/studies) 的结构化响应。NLM 的 [官方 API 公告](https://www.nlm.nih.gov/pubs/techbull/ma24/ma24_clinicaltrials_api.html) 说明 v2 采用 JSON、ISO 8601 日期和标准化字段。

选择已报告结果、登记为 `INTERVENTIONAL` 且分配为 `RANDOMIZED` 的研究，再要求快照中状态为 `COMPLETED`、首次结果公开日期不晚于 2025-12-31，并具有非空的主要测量结果单元。从读取的 API 遍历快照取前 250 个独立 NCT ID；这不是随机取样，也不代表全部疾病、干预或试验质量。

每条只保留必要登记字段、首次结果提交日期、首次结果公开日期及其类型、首个有测量的主要终点和最多 4 个结果单元，以及所需分组、分母与离散程度字段。**首次提交不等于首次公开；首次公开不等于研究完成。** `ACTUAL` 与 `ESTIMATED` 原样保留，不能把估计日期或人数改为确定值。

登记资料与结果由申办者或研究者提交。NLM 的 [官方教学全文](https://www.nlm.nih.gov/oet/ed/ct/full_picture.html) 说明质量控制主要检查表面错误、缺漏与不一致，准确性、安全性和科学有效性由申办者与研究者负责；[官方结果公开程序说明](https://www.nlm.nih.gov/pubs/techbull/jf20/jf20_clinicaltrials_qc.html) 也说明收录不构成 NIH 背书，部分结果可在质量控制尚未完成时公开。

本卡并未审查完整方案、预注册变更、失访、偏倚、组间统计分析或临床意义。登记为随机研究不等于本卡已证明疗效；一个结果单元也不是完整比较，不能由此形成治疗建议。

[NLM 数据下载与版权说明](https://www.nlm.nih.gov/databases/download.html) 区分美国政府作品与可能受保护的第三方内容，要求清楚标注 NLM 来源、避免背书暗示，并使用当前数据或显著声明数据并非最新版本。本库遵循历史快照声明，只保留最小登记与结果事实字段，不收录联系人、个体参与者数据、完整研究文本或附件；不宣称 ClinicalTrials.gov 数据统一属于 CC0。ClinicalTrials.gov 的部分说明页面在本次直接读取中只返回 JavaScript 页面壳，未将其列为完整条款正文已核验。

## 诺贝尔科研：150 个年度类别记录

读取 [Nobel Prize 官方 API v2.1](https://api.nobelprize.org/2.1/nobelPrizes?limit=1000) ，分别在物理学、化学、生理学或医学的截至 2025 年记录中取 50 个年度类别。每类按时间排序后等间隔选取索引 `round(i*(n-1)/49)`，`i=0..49`，保留相应年度全部获奖者、份额和授奖说明。同一年度类别的多个获奖者不能拆成多个案例。

这组记录跨越 1901 至 2025 年，用于沿授奖主题寻找原始研究；它不是完整获奖者数据库，不包含文学、和平、经济学案例集或菲尔兹奖案例库。获奖证明官方授奖记录，不证明后续应用成功、论文可复现或模型能迁移到当前具体问题。

[API 与 Linked Data 官方使用条款](https://www.nobelprize.org/about/terms-of-use-for-api-nobelprize-org-and-data-nobelprize-org/) 对这两个服务采用 CC0，同时规定存在冲突时服务条款优先、不得故意误导性更改数据或制造背书，并应降低 API 负担、优先缓存。该完整条款已读取并留存核查证据。API 数据许可不覆盖全部网站文章、照片、影片或徽标；本仓库不使用诺贝尔机构徽标。

## NASA LLIS、技术案例与原有模型来源

NASA 深度案例依据 [NASA 官方 MIKA 仓库](https://github.com/nasa/mika) 中固定提交 `ecbc1f12aca5317b6ea622bf49d956660bd0f19a` 的历史 LLIS 数据，将同一 Lesson ID 的 Driving Event、Lesson(s) Learned、Recommendation(s) 三字段合并，选择有具体驱动事件和决策用途的条目。记录不把建议写成已完成的整改，也不补猜缺失的事件日期。

三字段来自同一经验条目的事实基础，不是三个独立证据组。当前 LLIS 站点直接读取只返回页面壳，实际读取依据为官方固定版本；具体来源同时保留原 LLIS 链接、行定位、提交和摘要。发布的是原创中文改述与来源定位，不附三份原始全文快照；没有把公共访问或 NASA 域名当作统一 CC0 授权。

技术、种子案例和模型卡片按各自 `sources-*.json` 记录的实际来源判断。官方技术报告、论文、博客、事故复盘、管理框架和启发式的证据地位不同。只分发原创分析、必要事实和定位，不把来源网页全文纳入包中，不声称存在一个覆盖全部第三方材料的许可。

## 定位与验证

案例位于 `references/cases.json` 与 `cases-*.json`，来源位于 `sources-*.json`。事实事件的精简字段快照位于 `references/event-data/`，包含选择规则、原始记录键、读取 URL、时间与摘要；案例的 `provenance` 指向记录与快照。

`publisher` 是发布机构，`origin_group` 是信息来源组，二者可以不同。例如其他机构转述同一 CFPB 执法事实，不自动增加独立来源组。多个来源文件、多个 URL 或多个结果组也不能代替主张级证据。

`checked_on` 表示实际核查时间；`fact_confidence` 表示有限事实与所读来源的匹配程度，不是“现实事实正确率”；`causal_confidence` 单独表示因果支持边界。摘要用于检验打包与字段一致性，不是事实可信度证明。

从仓库根运行：

```text
python -X utf8 skills/civilization-os/scripts/catalog.py validate
python -X utf8 skills/civilization-os/scripts/verify_events.py
```

检查通过表示结构、引用与本地快照一致，不表示重新联网读取了 1000 个完整案例，也不表示全部主张已获得独立复现。需要当前数据、完整原文或因果结论时，应沿来源继续研究。
