# 模型检索索引

本索引用于先选模型，再按编号读取卡片。所有卡片均含定义、机制、所需输入、公式（适用时）、适用边界、误用、来源和案例连接。来源可靠性与模型可迁移性需要分别判断。

| 任务 | 优先候选 | 补充判断 |
| --- | --- | --- |
| 不确定性与选择 | P004、P005、P007、P058、P094、P096 | P087 校准，P088 时间价值 |
| 日常生活与人生取舍 | P007、P028、P052、P058、P088 | 先理清个人价值，无法量化的取舍保留文字 |
| 关系、家庭与共同安排 | P054、P076、P082、P085 | 区分行为与动机猜测，尊重意愿，不强套商业机制 |
| 商业与创业 | P056、P063、P065、P077、P095 | 有具体条件再用 P060／P061／P062 |
| 职业与成长 | P058、P068、P089、P094 | P028 有限理性，P030／P047 学习 |
| 学习与科学解释 | 对应学科模型、P030、P098 | P099 检验预测，不强行跨域 |
| 核验因果与案例 | P050、P086、P098 | P036、P054 检查偏差 |
| 组织与流程 | P026、P064、P078、P079、P082 | P080 文化是机制候选，需数据 |
| 风险与反例 | P083、P087、P092、P093、P094 | 黑天鹅／灰犀牛只作风险视角 |

这些是检索入口，不是固定配方或领域白名单。未列举的人生决策也从具体问题选择模型，简单问题可以不用模型；选择由用户价值、具体变量与适用前提决定。

获奖研究的详细前提、证据与使用步骤另见 [research-index.md](research-index.md)；研究卡不增加 P 模型数量。用检索器查模型时，结果的 `research_card_ids` 提示有关联的 A 卡；只在它能改变当前判断或帮助理解时读取，模型连接不是迁移效果的证明。

## 读取方法

- P001-P050：[models-01.json](models-01.json) 。
- P051-P100：[models-02.json](models-02.json) 。
- 案例：[cases.json](cases.json) 。
- 模型出处：[sources-01.json](sources-01.json) 、[sources-02.json](sources-02.json) 。
- 案例出处：[sources-cases.json](sources-cases.json) 。

有 Python 时执行 `catalog.py show P058`，或关键词 `search "机会成本"`。检索分数是文本匹配，不代表证据等级或决策权重。

## 相对原对话的目录修正

保留 100 个模型卡范围，但修正重复或过于宽泛的条目：P028 改为有限理性，P037 改为基准率，P050 改为因果推断，P088 改为时间折现；学习、记忆、平台等泛名进一步具体化。自然规律、认知机制、经验研究与启发式分开标注；P100 文明周期假说明确保留争议状态。

目录编号以本包为准。原对话存在不同版本的 P001 等编号，不能混用。相近模型可以有不同分析角色，但不能当成两份独立证据。
