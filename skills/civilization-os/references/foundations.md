# 底层机制导航

当问题跨越多个领域，先找需要改变的判断，再选相应机制。这里把已有 P 模型组织成阅读入口，不新增模型，也不把相近名称当成多份独立证据。先读少量相关卡片即可；简单选择可以不用模型。

个人目标与价值是输入，不由概率、效率或自然规律替人决定。模型目录和应用步骤见 [model-index.md](model-index.md)；具体学科与行业入口见 [discipline-index.md](discipline-index.md)。这些分组是菜单，不是领域白名单或完整理论体系。

## 从当前问题选机制

| 要改变的判断 | 先问什么 | 可选 P 模型 | 希望得到的具体产出 |
| --- | --- | --- | --- |
| 概率、证据与因果 | 参照群体是谁？新证据区分了什么？改变动作是否真改变结果？ | P004、P005、P037、P050、P087、P096 | 可比的结果情景、证据更新或尚不能识别的因果缺口；没有依据时不编概率 |
| 约束、取舍与时间 | 哪些底线必须守住？替代方案是否可行？从现在起要放弃什么？ | P007、P028、P052、P058、P088、P094 | 可行选项、用户认可的取舍和退出条件；非金钱价值保留文字 |
| 信息、解释与核验 | 谁知道关键事实？新增信息会改变哪个动作？故事中什么尚未证实？ | P006、P044、P053、P054、P077 | 值得查的关键未知、竞争解释与核验办法；信息量不等于真实性 |
| 连接、反馈与延迟 | 哪条依赖或回路影响结果？动作多久见效？观察信号是否可靠？ | P008、P020、P026、P082 | 最小依赖图或反馈图、观察窗口与调整办法；箭头须有机制或证据 |
| 合作、激励与责任 | 各方真正想要什么？谁能观察、决定和履约？规则是否得到同意？ | P009、P040、P057、P076、P078、P079 | 可沟通的责任、分工和规则；均衡或总收益不代表公平，不猜测他人动机 |
| 环境变化、探索与保留能力 | 变化发生在哪里？旧优势因何失效？尝试新路要承担什么成本？ | P024、P032、P089、P090、P091 | 环境假设、探索预算或替代路径；生物适应与冗余只是原学科机制，生活应用须另有依据 |
| 学习、行为与选择环境 | 要提高哪种表现？现有触发、反馈与摩擦是什么？熟悉感和掌握是否不同？ | P030、P036、P046、P047、P049、P051 | 可执行的练习或行为调整、检验方式；不承诺固定天数或普遍效果 |
| 推理、检验与更新 | 前提可靠吗？什么观测区分解释？什么结果会使判断改变？ | P002、P054、P084、P086、P098、P099 | 可核验主张、对照或反例、结论的保留范围；逻辑有效不等于前提真实 |

候选不是配方。例如概率与因果常一起出现，但同一个问题未必需要同时读六张卡。优先选择能改变当前某项判断的模型；不要只因名词相似而调用。

## 需要原学科知识时

| 目的 | 阅读入口 | 不能省略的条件 |

| 学数学结构、变化率和证明 | P001、P002、P003、P004、P007、P008、P010；相关菲尔兹研究 A013-A016 | 定义对象、单位、公理与量词；数值算例不证明一般定理，存在性不保证高效算法 |

| 学遗传、演化、生态或免疫 | P021、P022、P023、P025、P031、P032、P033；节律研究 A009 | 区分个体、种群与生态层级；描述自然过程不提供伦理结论或个人诊疗方案 |

这些区间供定位，不是一次读取要求。完整名称与文件分区见 [模型索引](model-index.md)。研究卡的原理、版本和成立条件见 [研究索引](research-index.md)，不在这里重复正文。

## 沿证据继续读

1. **先读原模型。** 核对 `core`、`inputs`、`limits` 与 `misuse`，再读 `application` 的适用状态、输入／动作／产出、教学例子、反例和停止条件。`decision_support` 辅助条件分析；`learning_only` 留在知识学习；`analogy_only` 必须补充具体问题的机制与证据。状态不是效果评分。
2. **需要研究深度时读 A 卡。** 例如损失与表述读 A001，共同安排的规则读 A004，寻找足够好的方案读 A005，质数与曲线计数学习读 A014／A015。核对研究条件及 `transfer_note`；获奖声望不能替代支持当前主张的证据。
3. **需要历史对照时查 C 卡。** 先按问题与机制检索，再核对完整记录与来源。`deep_case` 可支持有限复盘；`evidence_event` 只支持所存字段，不能补造历史行动或因果。没有匹配案例，不影响先分析当前选择。
4. **专有知识缺失时补源。** 用 [学科与行业导航](discipline-index.md) 确定应查的专业事实与当前条件；查不到时说明缺口，继续完成有依据的部分。

操作步骤和反例是项目新增的应用整理；原创教学例子不是历史案例，也不是新的研究效果证据。P 模型、A 研究和 C 案例保留各自身份，关联不等于当事人实际使用过该模型。

路径相对于本 Skill。把 `<skill-dir>` 换为安装目录的绝对路径：

```text
python "<skill-dir>/scripts/catalog.py" show P058
python "<skill-dir>/scripts/catalog.py" show A005
python "<skill-dir>/scripts/catalog.py" search "约束" --cases --record-type deep_case --model P007 --limit 5
```

没有 Python 时，按 [模型索引](model-index.md)、[研究索引](research-index.md) 和 [案例索引](case-index.md) 直接读取文件。检索是关键词匹配，未命中不表示问题无解。

## 一个跨域入口例子

“课程已经付费，但内容不适合，还要不要继续？”先用 P052 区分无法收回的学费和接下来能改变的时间、退费或履约条件，再用 P058 比较真实可行的替代用途。若决定继续学习，再按所学能力选择 P030 或 P047 的练习方式。课程条款和实际学习目标另行核对；无需为了显得跨学科而引入物理、生物或奖项类比。
