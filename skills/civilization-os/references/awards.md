# 从获奖成果学习与取证

奖项是定位研究的入口。当前库预装 150 个诺贝尔科学奖事实事件：物理、化学、生理学或医学各 50 个年度奖项，年份截至 2025；同一年度类别的全部获奖人合为一条。它是精选年度记录，不是完整诺贝尔奖数据库，也不含菲尔兹奖案例库。选择规则与字段见 [case-index.md](case-index.md) 和 [event-data/nobel.json](event-data/nobel.json)。

## 先定位，再学习研究

从 `scientific_awards` 的 `evidence_event` 检索具体年份、人物或成果，读取完整主张及来源定位。奖项数据可支持官方记载的年份、类别、共同获奖者和理由；这些字段不能替代原始研究的证明、实验设计或复现证据。模型连接注明为本次分析。

按主题继续读取：

- 诺贝尔奖：查 [NobelPrize.org](https://www.nobelprize.org/) 对应年份与类别页面、获奖理由、Scientific Background、Nobel Lecture，再查原始论文和后续研究。
- 菲尔兹奖及未收录奖项：按需查 [国际数学联盟 Fields Medal 页面](https://www.mathunion.org/imu-awards/fields-medal) 等奖项的官方年份材料，再找原论文、作者讲义或权威大学材料。

实际打开来源；搜索摘要只用于定位。当前年份、最新名单或成果现状需当下官方核验；离线缓存不能回答最新变化。来源打不开时寻找可核对的官方镜像或作者版本，并说明所读版本。

## 学习路径

1. 明确成果、用户基础与应用目的；“全部／历届”先界定奖项、年份和学习深度。
2. 核对正式名称、年份、人物、共同获奖者及官方理由，不按共同获奖人数扩计案例。
3. 分开成果解决的问题、成立前提、研究证据、局限和与模型的联系。
4. 用直觉例子、必要的形式表述、反例和练习解释。严格证明需实际展开或指向可核对证明；原始研究的因果主张依 [evidence.md](evidence.md) 检查。
5. 迁移到现实决策时列出映射与断裂点。很多纯数学成果可用于知识学习，没有直接可操作的商业映射时保留这一边界。
6. 分开研究论断与获奖者的个人价值观点；获奖不为其其他言论提供科学担保。

用户授权扩库后，新增事实条目记录稳定事件身份、官方事实与定位；若要升级为深度案例，另核对历史决策、行动、结果和分析边界，并保留原案例 ID。完整奖项建设按授权范围执行，不从姓名表生成未经核验的研究故事。
