# 获奖研究怎样参与决策与学习

奖项帮助定位研究，具体研究的原理、前提与证据决定怎样使用。本库有两种不同材料：150 条诺贝尔科学奖事实事件，以及独立的 16 张获奖研究卡。两者不重复计入案例。研究卡覆盖 8 项经济学研究、4 项科学研究和 4 项菲尔兹相关数学研究，属于代表性精选，不是历届成果全集。

## 先选研究，再判断是否可用

从 [research-index.md](research-index.md) 或 `catalog.py search "关键词" --research` 找相关卡，`show A001` 读取完整内容。一般人生问题先用 [modes.md](modes.md) 理清价值与约束；只有研究会改变当前哪项判断时才引入，不按奖项声望或模型数量选择。

每张卡包含获奖关系、研究问题、机制或定理、原研究证据、成立前提、局限、卡内来源与主张，以及本库提出的使用步骤和教学例子。`reading_scope` 说明实际读取版本与章节，不代表审计了完整证明或全部后续文献。

| 应用状态 | 用法 |
| --- | --- |
| `direct` | 研究概念直接对应当前分析对象，仍核对前提、用户情况与证据，不意味着保证效果 |
| `conditional` | 有相关机制，但需要先确认环境、对象或可观测输入；先指出迁移距离 |
| `learning_only` | 用于知识理解、形式化练习与检验论证，不能据此生成具体人生建议 |

## 从研究到当前选择

1. 说明研究原本解决什么问题，哪些主张有来源支持。授奖理由说明整体贡献，不能把某篇论文说成单独获奖，也不能把获奖人的其他意见当作研究结论。
2. 检查成立前提与当前场景：行动者、信息、选择集合、时间尺度、测量和价值目标。例子是教学分析，历史故事和用户现实另行核验。
3. 指出研究改变的具体判断，例如换一种损益表述后偏好是否改变、支出是否被不同账户标签扭曲、合作规则是否容纳共同决策。一个发现可能只支持提问，不能自动证明应选哪个方案。
4. 给出适合当前处境的步骤、关键未知和停止条件。迁移属于分析者提出的连接，尚未经过个人生活效果试验；不编造效应大小、概率或最优答案。
5. 模型不适用时回到实际价值、约束和证据。不要用纯数学定理证明感情、道德或人生必然怎样，也不要从实验对象直接推出人类个人医疗结论。

## 数学成果的学习路径

菲尔兹卡保留原问题、定理前提和解释。先用直觉例子辨清对象，再看必要形式表述，最后用反例、边界与练习检查理解。理解定理不是完成证明；需要严格证明时继续实际阅读并展开相关步骤。没有直接生活应用时，知识学习本身就是交付，不强行类比。

## 未收录与当前成果

150 条 `scientific_awards` 事件只支持获奖年度、类别、共同获奖者与授奖理由，不能替代原论文。物理、化学、医学各精选 50 个年度，截至 2025 年；同一类别年度全部获奖人合成一条。取样见 [case-index.md](case-index.md) 和 [event-data/nobel.json](event-data/nobel.json)。

未收录主题按需读 [NobelPrize.org](https://www.nobelprize.org/) 的年度材料、Scientific Background、Nobel Lecture 或 [IMU Fields Medal](https://www.mathunion.org/imu-awards/fields-medal) 官方材料，再查原论文、作者讲义与相关后续研究。搜索摘要只用于定位，实际打开所引用来源。当前年份、最新名单和研究现状需当下核验，离线卡片不能回答变化。

来源打不开时找可核对的官方镜像或作者稿，记录具体版本、读取范围和剩余缺口。医学、法律及重大财务应用继续按 [evidence.md](evidence.md) 核查当前一手资料；研究卡不能直接决定个人诊疗或交易。授权扩库后按 [maintenance.md](maintenance.md) 的研究卡规则维护。
