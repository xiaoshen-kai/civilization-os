# 学科与行业问题导航

先按正在处理的问题找入口，再读取少量相关 P 卡及其 `application` 操作步骤。本页覆盖一些常见情境，菜单不是领域白名单：未列出的专业、行业或人生选择，仍可从 [底层机制导航](foundations.md) 的概率、取舍、反馈、信息和合作等机制开始。

**现有 100 个模型不是各学科完整理论库。** 本页的跨域关联是项目分析，不增加新模型或证据身份。哲学、法律、医学和设计等专有知识没有被系统收齐；需要时先查原理论、规范或专业资料，再判断模型是否适用。缺少匹配模型、研究或案例时，也可先理清用户价值、选项与关键未知。

## 从学科问题进入

| 学科或知识问题 | 关键问题与可选 P 模型 | 需要额外查什么 | 迁移边界 |
| --- | --- | --- | --- |
| 数学、逻辑与统计 | 对象和量词是什么？条件是否满足？P001、P002、P003、P004、P005、P007、P008 | 原定理的正式定义与版本、抽样机制、变量单位；算法还须查复杂度和实现条件 | 小算例不证明一般结论；统计拟合不直接给出因果或价值排序 |
| 物理、能量与动力系统 | 系统边界、尺度和初始状态是什么？P011、P015、P016、P017、P018、P019 | 方程、材料与测量条件、稳定性和近似范围；高速或微观主题另读 P012、P013、P014 | 管理中的“力”“熵”“临界点”不能代入物理公式证明效果 |
| 生物、遗传与生态 | 解释的是个体调节、遗传演化还是群落关系？P021、P022、P023、P024、P025、P031、P032 | 所涉物种、层级、环境与实验条件，原研究和适用的生态监测资料 | 生物适合度不是幸福或道德价值；组织与产品类比需独立检验 |
| 心理、认知与学习 | 改变的是判断、记忆、技能还是主观体验？P027、P036、P041、P046、P047、P048、P055 | 测量方法、研究人群、任务与对照；涉及心理健康判断时查当前专业依据与个体情况 | 不凭一次行为诊断人格或病症；马斯洛固定层级、心流及双系统均须保留原限制 |
| 经济与财务 | 稀缺资源、可替代选项和时间口径是什么？P056、P057、P058、P059、P068、P088、P094 | 当前价格、费用、税费、合同和现金流；估值或收益结论查最新一手披露 | 理论均衡不代表公平；复利公式不承诺正回报，非金钱价值不强制折现 |
| 社会、关系与组织 | 各方的意愿、身份、资源与决策权是什么？P009、P040、P043、P045、P076、P079、P080 | 当事人陈述、实际规则和重复行为；制度结论查具体制度与原研究 | 不把关系强套成交易或零和，不从群体标签推断个人动机 |
| 哲学、伦理与意义 | 分歧属于事实、概念、义务还是值得过的生活？P002、P044、P081、P084、P099 可辅助澄清 | 涉及某学派或论证时读哲学家原文和可靠学术版本；比较立场的理由与价值前提 | 当前卡片未系统覆盖伦理学、认识论或美学；科学检验不能替用户证明人生意义 |
| 法律、权利与制度 | 管辖地、事实、时间和所需法律后果是什么？P001、P002、P077、P078 可整理材料 | 当前有效法条、官方解释、合同原文、期限及适用判例；区分事实与法律评价 | 通用模型不能推出合法性或确定诉讼结果；专业知识缺口须补证，不以经济激励代替权利 |
| 医学与健康 | 当前症状、诊断依据、备选方案和本人目标是什么？P031、P050、P086、P098 可整理证据 | 个体病史、检查、禁忌和用药；当前指南、监管信息及针对同类人群的原研究 | 汇总试验结果不等于个人诊疗结论；本库医学知识不完整，可整理选项与专业沟通问题 |
| 设计、艺术与人机交互 | 为谁设计？希望改善理解、操作、情感还是表达？P007、P044、P048、P049、P071 | 用户任务与访谈、无障碍规范、媒介条件、作品语境及实际测试；引用设计理论时读原资料 | 点击或停留时间不等于体验与福利；现有卡片不是完整设计、美学或艺术理论库 |
| 历史与政治解释 | 比较哪些时期与制度？证据支持哪条机制？P044、P050、P086、P090、P100 | 一手史料、统计口径、文本年代、竞争解释；现实政策与事件须查当下官方资料 | 历史类比不能确定现实走向；P100 是争议假说，不给国家兴衰周期或投资时点 |

原学科定理、自然规律、经验研究和启发式应按各自证据地位使用。相关奖项研究见 [research-index.md](research-index.md)，包含数学、经济与科学的代表性研究，未覆盖上述所有学科。

## 从行业与工作情境进入

| 情境 | 要问的关键问题与可选 P 模型 | 何时必须补充领域来源 |
| --- | --- | --- |
| 教育、培训与职业成长 | 学会什么才算有效？练习、反馈与替代时间如何安排？P030、P047、P057、P058、P067、P089 | 涉及资格、考试、就业或课程承诺时，查当前官方要求、真实岗位和课程条款；记忆研究不能替代特定技能验证 |
| 软件、AI 与信息服务 | 输出如何核验？关键依赖、错误传播与恢复路径是什么？P006、P008、P026、P077、P082、P087 | 查实际版本的官方文档、源码／接口、权限、数据与故障记录；通用机制不能替代架构和安全专业知识，AI 自报置信度不是校准证据 |
| 制造、建筑与供应链 | 瓶颈和质量约束在哪里？备份是否共享风险？扩大产量真的降成本吗？P007、P026、P032、P060、P064、P073 | 设计、采购或实施前核对适用标准、物料参数、产能与供应商资料；不能用 NASA 经验跨过本行业规范 |
| 零售、服务与营销 | 客户需要什么？价格、质量信号与呈现如何影响选择？P042、P049、P053、P056、P065、P077 | 价格策略查成本、可比交易和合同；效果查对照与实际客群；投诉与宣传结论核对具体事实和当前规则 |
| 平台、媒体与社区 | 哪些用户真正互相影响？传播、留存和收益为何变化？P043、P061、P062、P069、P070、P071、P075 | 查平台规则、原始运营数据、用户网络与采样方式；人数多不是网络效应，偏斜分布不自动是幂律，传播量不证明真实或优质 |
| 金融、保险与创业 | 损失、现金、履约与退出条件是什么？P051、P065、P068、P088、P094、P097 | 查当前产品条款、监管披露、资产负债、费用与风险承担能力；银行失败记录不推导当前机构安全，历史收益不保证未来回报 |
| 医疗、护理与照护安排 | 选择取决于哪些个体资料、照护资源与本人意愿？P007、P050、P079、P086 | 医疗结论按上表补当前专业证据；照护安排核对实际服务、资格、费用和参与者意愿；不以单位成本决定人的尊严 |
| 公共服务、法律服务与共同资源 | 谁受规则影响、如何参与、监督和解决冲突？P040、P076、P078、P079、P082 | 查当地规则、授权、合同、申诉程序与实际资源；A004 只作条件分析，不能据研究声望证明某套规则适合所有群体 |
| 农业、能源与环境 | 资源流、季节、反馈与冲击影响哪个结果？P025、P026、P032、P091、P094 | 查当地观测、工程参数、环境标准和原领域模型；A012 的气候机制学习不替代地点、天气或产量预测 |
| 创意、产品与专业服务 | 目标用户、交付质量和差异化在哪里？P044、P063、P064、P072、P095 | 查用户研究、作品／技术条件、知识产权与交付条款；“破坏式创新”或“战略”标签不替代实际机制和验证 |

行业名称用于帮助辨认输入，不限制普通人的使用。搬家、消费、伴侣沟通、家庭责任、换城市或未知方向，均可先讨论本人价值与约束，再按需要借用上述机制和专业资料；行业指标不能成为所有人生问题的默认目标。

## 接到模型、研究与案例

- **P 模型：** 从 [model-index.md](model-index.md) 查名字，再用 `show Pxxx` 读原理、应用步骤和反例；这里只列候选，不认定它已经适用。
- **A 研究：** 从 [research-index.md](research-index.md) 读相关卡。预算标签可查 A002，满意解查 A005，质量与信号查 A006／A007，节律学习查 A009，病因证据学习查 A010，数学学习查 A013-A016。先核对应用状态与前提，不借奖项权威跳过问题定义。
- **C 案例：** 从 [case-index.md](case-index.md) 先看实际覆盖，再按机制少量检索。现有案例偏工程、监管、临床研究和科学奖项；没有同领域案例时不硬配。核对主张、出处和迁移边界后再引用。
- **新增专业事实：** 先把待核验问题写具体，例如“此地此时的退费条款是什么”或“该研究人群是否与此人相近”，再读当前一手资料；无法核验的条件保留为未知。

公开材料与历史记录不自动授权外部操作。分析可给出有条件的下一步，保存个人资料、发布、交易或联系他人仍须相应授权。
